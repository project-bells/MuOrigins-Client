# MuOrigins Client 0.97K

Ready-to-play English client for **MuOrigins 0.97K**.

## Server

- Website: https://muorigins.online
- Connect server: `play.muorigins.online:44405`
- Language: English
- Default resolution: 1280x768
- Client version: 0.97K / protocol 0.97.11

## Installation

1. Click **Code > Download ZIP** on GitHub.
2. Extract the complete archive to a writable folder.
3. Keep the `Data` directory beside `main.exe`.
4. Run `main.exe` as administrator if Windows blocks access to game files.

The client must be allowed through Windows Firewall to connect to the game server.

## Configuration

Display, audio, language, and anti-lag settings are stored in `Config.ini`.

Do not remove or rename files inside the `Data` directory.
